# GizeMate 1.6.0: artifact inventory

The published files of the GizeMate 1.6.0 GitHub release. Everything here was built from a clean tree at the commits named below; the details and the evidence are in [1.6.0-validation-record.md](1.6.0-validation-record.md).

## Provenance

- Branch `feature/gizemate`, cut from release v1.5.0 (`3d247af`), merged into `main` with a merge commit and tagged `v1.6.0` by the release process.
- Windows installers built from `94f7e72c50d604c9672ed0ac538a1e1615b15b30` (clean tree; recorded `git status` empty at build start). Android APK and AAB built from `3e950f981fb825cb308986881dd92158825bd7fc` (clean tree).
- Later commits changed tests, documentation and verification scripts only. `git diff 94f7e72 <release commit> -- src build electron-builder.yml package.json package-lock.json assets android` is empty.
- Version: desktop and web `1.6.0` (`package.json`); Android versionName `1.6.0`, versionCode `10600` (`android/version.properties`).
- The earlier release-candidate installers (`Desktop-Cat-Setup-1.6.0-*`, built from `57f7e83` and `25a884d`) are **obsolete and are not published**.

## Signing and trust

- **Windows: unsigned.** No code-signing certificate exists. SmartScreen warns and Smart App Control may block the installers. The release notes say so. Signing is an owner action (docs/platforms/windows-signing.md); a signed file would have a different hash.
- **Android: signed** with the project's existing release key (certificate SHA-256 `26ecf2c2f825b82b77b80eca5fdab21eaea7aa5397ecab2c4a0c473eb394f4ab`), the same key as the 1.5.0 build. Not a Google Play download, so Play Protect may still ask for confirmation.
- **Google Play: not submitted.** The AAB and the draft materials in `docs/store/google-play/` are prepared; submission needs the owner's separate authorization.

## What is not covered

The installers were never executed; ARM64 never ran; the Android build was never run on a device or emulator by the builders; sound was measured but not heard; no screen-reader or multi-monitor check. See [known limitations](1.6.0-known-limitations.md).
