# GizeMate 1.6.0: install and upgrade (Windows)

Files: `Desktop-Cat-Setup-1.6.0-x64.exe` (Intel/AMD) or `Desktop-Cat-Setup-1.6.0-arm64.exe` (Windows on Arm). Check the SHA-256 in [1.6.0-artifact-inventory.md](1.6.0-artifact-inventory.md) before running (`Get-FileHash <file>`).

## Clean install
Run the installer. SmartScreen will warn because the file is unsigned: More info, Run anyway (only after the hash matches). It installs per user (no administrator rights), asks for a folder, creates Desktop and Start menu shortcuts and starts the app.

## Upgrade from 1.5.0 or earlier
Run the new installer over the old one. It keeps the same application id, install folder, data folder (`%APPDATA%\Desktop Cat`) and Windows startup entry, so your cat, settings and memory are kept. Uninstalling does not delete your data (the installer is configured not to). **Back up `%APPDATA%\Desktop Cat` first** if you want a safety copy. This behaviour is read from the installer configuration and the earlier upgrade logic; it has not been observed by running the 1.6.0 installer.

## Uninstall
Apps and features, or the Uninstall entry in the install folder. Your data folder is kept. Delete `%APPDATA%\Desktop Cat` by hand to remove everything.

## First launch
The settings window opens on first run. Language is Automatic (Windows language) unless you change it. Choose a companion under Characters. Sound is off until you turn it on.
