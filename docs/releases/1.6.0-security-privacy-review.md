Scope: the diff from v1.5.0 (`3d247af`) to `f40cc50`, plus the shipped Windows payload. Labels: REAL (executed here), REVIEWED (read, not executed).

| Area | Result | Evidence |
|---|---|---|
| Dependencies, shipped | 0 known vulnerabilities (REAL) | `npm audit --omit=dev`: 0 of every severity |
