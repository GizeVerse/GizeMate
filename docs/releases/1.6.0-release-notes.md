# GizeMate 1.6.0

**GizeMate is a small universe of companions that live on your screen.** Version 1.6.0 turns the cat you may already know (GizeCat, formerly Desktop Cat) into a multi-character product with seven companions, two languages and a new settings window. Windows and Android.

> **Signing status:** the Windows installers are **not code-signed** (no certificate was available), so SmartScreen will warn. The Android APK and AAB are signed with the project's release key. The Windows installers have never been executed by the builders; see *What was and was not tested*.

## The seven companions
| Companion | How it moves | A little about it |
|---|---|---|
| **Cat** | walks, runs, stalks, climbs window edges | The original: your existing cat, with its name, coat and memory, is kept. |
| **Monkey** | knuckle-walks, climbs, swings, hangs from ledges | The acrobat: playful, restless and a little mischievous. |
| **Fox** | trots, stalks, pounces; can slip away in a soft vanish and reappear | Clever, quick and a little aloof; loyal once it trusts you. |
| **Rabbit** | hops, squashes on landing; can burrow | Affectionate, bubbly and a little timid. |
| **Ghost** | floats and bobs, fades out and back in | The harmless haunter: a playful prankster, never scary. |
| **Slime** | bounces, squashes and wobbles | The bouncy blob (in Turkish, Jöle): playful and affectionate. |
| **Alien** | glides just above the ground | The curious visitor (in Turkish, Uzaylı): endlessly curious and unpredictable. |

One companion is on screen at a time. Each has its own look and colours, personality, voice, memory and journal, and you can give each its own name.

## What is new
- **Character selection and a simpler settings window** with four areas: Home, Characters, Customize and Settings.
- **English and Turkish.** Automatic follows your system language; you can choose either one yourself. Menus, settings, dialogs, character texts and world events follow it.
- **Voices.** Every companion has its own sounds. Sound is off until you turn it on.
- **A living, calmer companion.** Autonomous behaviour with moods, memory and small world events, with each character reacting in its own way.
- **Accessibility.** Keyboard navigation and visible focus in the settings window and the Android/web panel, labels for assistive technology, reduced-motion support and contrast checks.
- **Name and files.** The app, installer, shortcuts and Android app are now called **GizeMate**. Your data stays where it was, so updating keeps your companion (see below).
- **Fixes.** Many behaviour and reliability fixes found while running the full test suite for the first time, including touch handling in the web/Android panel.

## Install
**Windows 10/11:** download `GizeMate-Setup-1.6.0-x64.exe` (or `-arm64.exe` for Windows on Arm), check it against `SHA256SUMS.txt`, run it. No administrator rights are needed. **The installers are not code-signed**, so Windows SmartScreen will warn: choose *More info → Run anyway* only after the hash matches.

**Android 10 or later:** download `GizeMate-1.6.0-android.apk`, check its hash, open it and allow installation from that source. Then tap *Float over apps* in the app and grant *Display over other apps* yourself. `GizeMate-1.6.0-android.aab` is the Google Play bundle, not for sideloading.

## Updating
- **Windows:** run the new installer over your current one (quit the companion from its tray menu first). Same install folder and data folder (`%APPDATA%\Desktop Cat`), so your companion, settings and memory carry over; the old "Desktop Cat" shortcuts are replaced by "GizeMate" ones. The program file and data folder keep their old internal names on purpose.
- **Android:** the APK is signed with the same key as the 1.5.0 build and has the same package, so it installs over it and keeps your companion. The older debug-signed "GizeCat (trial)" builds are a different app: use *Take your companion to another device* to move your cat, then remove the trial.

## Privacy
Unchanged. Nothing is uploaded, there is no account and no telemetry. Screen analysis and cloud features are **off by default** and opt-in. GizeMate never reads keystrokes, typed text or the clipboard. Android declares the same four permissions as before.

## What was and was not tested
- **Tested (by the builders, Windows 11 PC):** type check, lint and 5,600+ unit tests; a real-app desktop test suite on Windows; a web-panel test suite in Chrome and Edge; the packaged Windows x64 app launched with each of the seven companions; static inspection of both installers; an accelerated 12-minute soak of all seven companions.
- **Not tested:** the Windows installers have never been executed (install, update and uninstall are analysed from configuration, not observed). Windows on Arm has never run on ARM hardware. The Android build has not been run by the builders (no emulator or device test); the owner tests it on real devices. Sound has been analysed by measurement but not listened to by the builders. No screen-reader session, multi-monitor or mixed-DPI check.
- Full list: [known limitations](1.6.0-known-limitations.md). Details: [validation record](1.6.0-validation-record.md).

## Known limitations (short)
One companion at a time; a saved profile still carries the cat only; a companion walking right at a screen edge can touch the window edge by a few pixels; Turkish text has had no native-speaker review; Android notification text follows the device language; Windows installers unsigned; macOS and iPad are not part of this release.
