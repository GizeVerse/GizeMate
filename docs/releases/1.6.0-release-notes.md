# GizeMate 1.6.0: release notes

GizeMate is the provisional name of the product (formerly Desktop Cat / GizeCat). The installer, install folder, saved data and Windows startup entry keep their existing names, so an installed copy upgrades in place and keeps its cat.

## What is new
- **Seven companions.** Your cat plus Monkey, Fox, Rabbit, Ghost, Slime and Alien. One companion is on screen at a time. Each moves differently (walk, hop, float, bounce, glide), has its own look and palettes, personality, voice and special behaviours. The fox can slip away and reappear; the rabbit can burrow; the ghost fades; the slime squelches.
- **Each companion keeps its own memory.** Names, personality drift and journal are stored per companion; the cat's data is untouched.
- **English and Turkish.** Automatic (follows Windows), or choose a language in Settings. Menus, settings, dialogs, character texts and world events follow it.
- **A simpler settings window** with four areas: Home, Characters, Customize, Settings.
- **Voices.** Each companion has its own sounds. Sound is off by default.
- **Accessibility.** Keyboard navigation and visible focus in the settings window and the web panel, labels for assistive technology, reduced-motion support, contrast checks.
- **Fixes.** Several long-standing behaviour and test fixes found while running the full suite for the first time (see CHANGELOG).

## Privacy
Unchanged: screen analysis and cloud features are off by default; no telemetry, no keyboard hook, no clipboard capture. See docs/PRIVACY.md.
